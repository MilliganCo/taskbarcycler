TaskbarCycler 1.0
=================

Назначение
----------
Обычный левый клик по значку запущенного приложения на панели задач Windows 11
автоматически работает как Ctrl+клик. Если у приложения сгруппировано несколько
окон, каждый следующий клик переводит фокус на следующее окно этой группы.

Если окно одно или приложение только закреплено на панели задач, Windows
обрабатывает клик обычным образом.

Установка
---------
1. Распакуйте архив в любую папку.
2. Запустите install.cmd обычным двойным кликом. Права администратора не нужны.
3. Утилита соберется штатным .NET Framework Windows, установится в:
   %LOCALAPPDATA%\TaskbarCycler
4. TaskbarCycler сразу запустится и добавит себя в автозапуск текущего пользователя.

Использование
-------------
- Кликайте по значкам программ на панели задач как обычно.
- Если у программы несколько окон, они будут открываться по кругу вперед.
- Левый клик по значку TaskbarCycler в трее временно включает/выключает функцию.
- Правый клик по значку в трее открывает меню:
    * Переключение окон включено
    * Автозапуск с Windows
    * Выход

Тест без установки
------------------
Запустите run_portable.cmd. Он соберет и запустит программу прямо из текущей папки.
Автозапуск при этом сам по себе не включается.

Удаление
--------
Запустите uninstall.cmd.

Технически
----------
TaskbarCycler не заменяет Проводник и не модифицирует explorer.exe.
Он ставит низкоуровневый хук только на мышь и через Windows UI Automation проверяет,
что клик пришел именно по кнопке приложения на панели задач. На время такого клика
он автоматически удерживает Ctrl, используя штатное поведение Windows.

Кнопка Пуск, Поиск, Представление задач, системный трей и правый клик не должны
перехватываться.

Исходник находится в TaskbarCycler.cs.
